### ⚡ Relay
**Crash-safe runtime for AI agents**<br/>
[Live demo](https://relay-project-murex.vercel.app/) · [Code](https://github.com/codedchaitanya/Relay-Project)

Every model call and tool call is written to a write-ahead ledger in PostgreSQL. Kill a worker mid-run and another
one takes over at the exact step, without paying for a model call twice or repeating a side effect.

- **196 / 196** runs killed mid-flight still finished, **0** duplicate writes
- Leases + fencing tokens, `SKIP LOCKED` claiming, idempotency keys
- **15.6×** throughput from 1 → 16 workers (1.18 → 18.4 runs/s)
- Retries with circuit breaker, dead-letter queue, Prometheus `/metrics`, tenant API keys and rate limits

`Python` `FastAPI` `PostgreSQL` `Docker` `Gemini`
